# 大 QMT 内置版 ETF 稳健折价猎手实施计划

> 目标：将 `strategies/潮汐量化-ETF稳健折价猎手.py` 的实际选股与交易行为迁移为大 QMT 模型交易内置 Python 单文件策略，先在独立模拟账户观察。

## 迁移契约

- 冻结当前源码的实际参数和公式：单只 100%、前日成交额 `[500万, 1亿)`、开盘折价 `<= -1%`、`open_premium - current_premium > 0.4` 时过滤、可用现金口径目标市值、无有效候选清仓、止损 5%、止盈 10%、持有 2 个自然日。
- 聚宽数据/调度/下单 API 替换为 QMT API；删除 Redis 中转，不修改原聚宽策略与现有跟单执行器。
- 正常的空候选仍清仓；行情、净值或账户 API 异常时停止当次交易并记录错误，不把平台故障误判为清仓信号。
- QMT 委托使用当前执行端参数：指定价、对手盘跨 3 个 ETF tick、2% 参考价偏离保护、0.5 秒单次超时、最多 20 次、15 秒总预算。
- QMT 单线程内不阻塞等待；使用定时驱动与回调推进 FIFO 委托，卖出终态且持仓更新后再计算买入。

## 文件与验证

1. 新增 `tests/test_qmt_builtin_discount_hunter.py`，先锁定纯策略公式、目标仓位、风控、定价和异步阶段切换。
2. 新增 `strategies/潮汐量化-ETF稳健折价猎手-QMT.py`，保持 Python 3.6 语法兼容、UTF-8 编码和单文件可部署。
3. 运行聚焦单测、Python 3.6 语法解析、UTF-8 编译检查，再运行仓库全量单测。
4. 本机不宣称验证真实 QMT 字段、ETF NAV 口径或模拟账户成交；这些在 QMT 客户端按运行清单核对。
